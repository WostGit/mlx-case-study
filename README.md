# PACXAI: Lean-Checked Transcript Privacy Audits

This repository is generated by a single self-contained GitHub Actions YAML file.

Core claim:

> If a student artifact is a deterministic function of the audited transcript, every finite recovery attack on the student has an equivalent transcript-level simulator with exactly the same empirical success count.

If the real training pipeline uses auxiliary data not included in the audited transcript, the theorem does not apply.

Run:

```bash
lake build
bash scripts/audit.sh
python3 experiments/run_distillation_audit.py
```

This artifact mechanizes finite recovery/privacy audit logic. It does not claim full Shannon/Gaussian/rate-distortion formalization.
